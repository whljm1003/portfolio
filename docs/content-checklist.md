## 정량 성과

현재 브랜치의 성과 레이아웃은 유지하며 실제 수치는 입력하지 않았다. 모든 지표는 `status: "pending"`, 전후 값·변화·측정 기간·출처는 `null`이다.

- `portfolioImpactMetrics`: 사용 흐름 완료율·반복 오류 발생률·배포 소요 시간
- `featuredProjects[].impactMetrics`: 로그아웃·앱 연결·OTA·빌드 배포·오류 원본 위치 확인
- 작성 영역: **개선 전후 값 / 동일한 비교 조건 / 기간 / 출처 / 개인 기여 작성 필요**

수치만 입력해서는 공개되지 않는다. 실제 측정 자료와 역할이 확인된 항목만 `verified`로 변경한다. 측정하지 않은 지표는 임의 수치로 채우지 않고 실제 확보한 근거에 맞춰 지표를 변경한다.
